# 📡 Delivery Express - Sistema de Controle de Entregas

![Sistema de Delivery]([https://via.placeholder.com/800x400?text=Delivery+Express](https://kevlps.github.io/delivery-express/))

Sistema web para pequenos negócios de delivery (pizzarias, hamburguerias, restaurantes) controlarem seus pedidos de forma simples e eficiente.

## 🎯 Problema que resolve

Donos de delivery enfrentam dificuldades para:
- ❌ Controlar os pedidos no papel
- ❌ Clientes perguntando "cadê minha entrega?"
- ❌ Funcionários se confundindo com prioridades
- ❌ Perder informações quando o papel some

## ✅ Solução

**Delivery Express** oferece:
- 📝 Cadastro rápido de pedidos
- 📋 Lista organizada com todos os pedidos
- 🏷️ Status atualizável (Preparando → Saiu → Entregue)
- 📊 Cards de resumo automático (total, entregues, em aberto)
- 💾 Dados salvos no localStorage (não somem ao recarregar)
- 📱 Layout responsivo (funciona no celular)
